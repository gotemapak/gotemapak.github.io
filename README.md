# gotemapak.github.io

Корень домена `gotemapak.github.io`. Здесь лежат только служебные файлы:
- `yandex_311461a2c8f6c26f.html` + meta-тег: подтверждение прав в Яндекс.Вебмастере. Яндекс проверяет права на весь хост, а не на подпапку.
- `robots.txt`: краулеры читают только корневой файл, поэтому здесь разрешён весь хост и указан sitemap сайта бота.
- `<key>.txt`: ключ IndexNow.
- `index.html`: переадресация на https://gotemapak.github.io/listen-youtube-bot/ (noindex).

Сам сайт бота лежит в репозитории `gotemapak/listen-youtube-bot`.
